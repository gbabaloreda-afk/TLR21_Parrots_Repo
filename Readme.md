# All three parrot superfamilies have lost TLR21, the immune sensor birds use to detect bacterial and viral DNA Supporting data, code, and figures for a comparative genomics study showing that TLR21 is absent across parrots. The analysis uses locus reconstruction, spanning long reads, transcript searches, and detection-sensitivity analyses to tell genuine gene loss apart from assembly dropout. The full research archive is available under Releases. Author: Ghazi Reda, Independent Researcher
